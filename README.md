# Scambodia public prototype v0.2.3

Native GDevelop visual-event prototype with PNG placeholders. This increment improves the offline Graybox movement lab: floor bounds, prop collision/depth, foreground fading and bounded camera zoom. It is not Map01 or the campaign.

Open the source in GDevelop Web Editor:
https://editor.gdevelop.io/?project=https%3A%2F%2Fraw.githubusercontent.com%2FThienVu2103%2Fscambodia-playtest%2Fmaster%2Fscambodia.json

Local test: Enter at Start; 1–5 select one local role; WASD/arrows move; Z zooms out, X zooms in, R resets zoom; Esc returns to Start. Try the floor edges and walking behind/in front of the blocks. Five placeholders on one screen are not five online players.

OnlineLobby and OnlineArena retain the previous native multiplayer spike. A reported two-player connection error after Start remains unresolved. Five-client, ownership replication, reconnect, host migration and checkpoint acceptance have not passed. This increment does not claim to fix networking.

Public source, Editor imports, saved Cloud copies and gd.games live releases are separate versions. Save existing Editor work before reopening a newer source. An old Cloud copy does not update automatically. This GitHub update does not publish a gd.games release; the owner controls Cloud save and release actions while preserving the game identity.

Only public prototype content belongs here. No custom game scripts, account tokens or production character/movie art are included.
