# Scambodia v0.6.7 — atomic common detector recipe

Night2 now has finite shared bench supplies and an optional common detector recipe. This is groundwork for Phase D crafting, not the character Assemble ability or a generic inventory.

## Test the recipe

1. Preview Start and click the canvas. Press B for the normal Day1 → Night1 → Day2 route. Leave the Day2 cargo box unsolved; ready the roles with N and press Enter into Night2. T remains an already-installed detector tutorial, so it does not test this new output route.
2. Select a role (1–5 offline). Move with WASD/arrows to A(1,0), stop unseen, release/press E: one team component. Repeat E cannot farm it.
3. At B(3,2), stop unseen, release/press E: one scrap. Release/press E again to start five seconds of automatic work. Releasing E continues; another fresh E by the crafter cancels. Movement, detection, capture, downing, H/skills and ownership/context/phase changes interrupt without cost. A peer cannot take over or cancel the lease.
4. At four seconds stock remains unpaid. At five seconds exactly one component and one scrap are spent together; the same singleton detector is carried by the crafter. Carry it to G2(4,4), release/press E to install and use the ordinary board/plan route.
5. Existing stashed/carried/installed output rejects crafting. Confiscated output can be reclaimed with unused stock, keeping id1 and one grant. Retry retains supplies/claims, costs and output; a fresh scene resets the session. B is a temporary prototype workbench mapping; materials are shared bench stock.
